# dalenstudios.com

The website of Dalen Studios. Plain HTML, CSS and a little JavaScript; there is nothing to install.

- `index.html`: the start page
- `privacy/index.html`: the privacy policy (app stores link to /privacy/)
- `404.html`: shown for unknown addresses
- `assets/`: styles, the sky script, pictures and the font (Jost, SIL Open Font License)
- `_redirects`, `_headers`: read by Cloudflare Pages
- `googlee849cc18d994e24b.html`: Google site verification, keep it

Cloudflare Pages builds it with `jekyll build` and serves `_site`. Jekyll only copies the files.
